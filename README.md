# Hamadan Stores — E-commerce Concept Demo

A responsive storefront concept built with plain HTML, CSS, and vanilla JavaScript.

## Run locally

1. Extract the project folder.
2. Open `index.html` in a modern browser, or run a local static server from this directory (recommended):
   - Python: `python -m http.server 8000`
   - Then open `http://localhost:8000`
3. An internet connection is needed for the Google Fonts and remote Unsplash sample images.

## What's interactive

- Responsive mobile navigation and search panel
- Category filters and product search
- Sample product detail modal with size/color selection
- Cart drawer with quantity updates and remove controls
- Cart saved in this browser's `localStorage`
- WhatsApp links and generated sample-item inquiry message
- Three branch direction links
- Simulated checkout feedback

## Important demo limitations

- Products, images, prices, sizes, and colors are illustrative sample data, not verified Hamadan Stores inventory.
- There is no backend, database, real stock checking, customer account, order storage, payment gateway, or secure checkout.
- The checkout button does not place a real order. It opens a WhatsApp inquiry and displays a demo notice.
- The displayed prices are examples and must be replaced with owner-approved prices.
- Branch map links are search links based on the provided descriptions; exact pins, hours, and phone numbers should be verified with the owner.
- Delivery is mentioned as available, but delivery areas, fees, timing, and return/exchange policy are not yet confirmed.
- Product photography is loaded from remote Unsplash URLs for the prototype and should be replaced with approved product photos for production.
- The saved-item heart is currently a visual demo interaction only.

## Before production launch

1. Obtain the original logo and brand assets.
2. Collect approved product images, SKU, category, sizes, colors, and prices.
3. Confirm the store's existing inventory/POS system and stock by branch.
4. Choose a backend or commerce platform and implement server-side order and inventory validation.
5. Confirm delivery areas/fees, pickup workflow, payment methods, returns, privacy terms, and order notifications.
6. Configure the store's domain, hosting, analytics, SEO metadata, accessibility checks, and production testing.
7. Keep advertising and customer data accounts under the store owner's ownership.
